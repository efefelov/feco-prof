## Архитектура продукта (3 слоя)

1. **Азимут** — 30 вопросов по открытой типологии Голланда (RIASEC), 12 минут → карта склонностей (6 шкал 0–10) → **гипотезы направлений, НЕ вердикты** → план проверки руками (2–3 реальные пробы до решения)
2. **Икигай-лист** — саморефлексия по 4 кругам (люблю / умею / миру нужно / платят), 12 текстовых полей, пользователь пишет сам; синтез: 4/4 подтверждённых круга = «кандидаты икигая», 3/4 = «рядом» (показан недостающий круг как задание); «формула икигая» со статусом «гипотеза на 3–6 месяцев»
3. **📄 Единый отчёт (PDF)** — обе части в одном документе: радар RIASEC (SVG), диаграмма 4 кругов (SVG), расшифровка каждого типа (выраженный/низкий — честные формулировки), сочетание top-2 (15 комбинаций), слепые зоны (низший тип), план на 12 месяцев по возрасту, границы методики. Скачивается через «Печать → Сохранить как PDF» (print-стили: светлый лист)

3 аудитории (переключатель): 8–9 класс / 10–11 класс / студент-взрослый (выгорание, смена направления).

## Этика и научная база — КРИТИЧНО, не нарушать

- **Цена ошибки в профориентации = судьба человека.** Архитектура защиты: гипотезы-не-вердикты; обязательные пробы руками; живой консультант для платной глубокой диагностики; пересмотр через 1–2 года; расхождение с ощущениями = ценность, не ошибка; честные границы инструмента (RIASEC не измеряет способности/характер/пригодность)
- **«Методика МГУ» в продукте НЕ используется и не воровалась:** методики МГУ-экосистемы (ЦТР «Гуманитарные технологии», создан на базе ф-та психологии МГУ) — лицензионные. Путь подключения — партнёр-психолог с сертификацией («Школа профконсультанта»). В UI есть карточка «Научная база — честно» (на старте и в отчёте)
- Никаких «гарантий выбора профессии», диагнозов психики; с несовершеннолетними — согласия родителей
- Икигай: диаграмма 4 кругов — западная адаптация (Уинн, 2001) японского ikigai; это указано в UI. Рамку популяризует Денис Скуратовский (t.me/DSrupt_mafia, skuratovsky.pro, аудитория — предприниматели) — потенциальный партнёр по взрослому треку; интегрируем метод, не чужой бренд
