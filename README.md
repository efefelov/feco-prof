# feco-prof — Азимут: карта склонностей + Икигай-лист + единый отчёт

Бесплатный вход в вертикаль профориентации, теперь в три слоя:

1. **Азимут** (RIASEC, 30 вопросов, 12 минут) — карта склонностей: результат — гипотезы направлений (не «профессия-вердикт») + план проверки руками.
2. **Икигай-лист** — саморефлексия по 4 кругам (люблю / умею / миру нужно / платят): достраивает то, что тест измерить не может. Синтез: 4 подтверждённых круга = «кандидаты икигая», 3 = «рядом» (показан недостающий круг как задание). Финал — «формула икигая» со статусом **рабочая гипотеза на 3–6 месяцев**.
3. **📄 Единый отчёт (PDF)** — обе части в одном документе: радар-диаграмма RIASEC, диаграмма 4 кругов, расшифровка каждого типа (что значит выраженный / низкий), слепые зоны, план на 12 месяцев по возрасту, границы методики.

**Монетизация v1:** базовый отчёт бесплатно; **расширенная интерпретация** (сочетание типов, слепые зоны, план на 12 месяцев) — 290 ₽ / код разблокировки. Оплата: ссылка в `PAY_LINK` (Продамус/Бусти/Т-Банк). Кодовая разблокировка — честный v1: не криптостойкая, но приватная (без аккаунтов) и достаточная до появления кабинета.

**Онбординг:** стартовый экран с 3 шагами, правилом «гипотезы-не-вердикты» и карточкой «Научная база — честно».

## Научная база — честно

Текущая основа — **открытая типология Голланда (RIASEC)** + икигай-рамка (западная адаптация Уинна, 2001). **«Методика МГУ» в продукте НЕ используется**: методики МГУ-экосистемы (ЦТР «Гуманитарные технологии») лицензионные — подключение только через партнёра-психолога с сертификацией («Школа профконсультанта»). Это зашито в UI карточкой «Научная база» — цена ошибки в профориентации слишком высока для воровства методик.

## Три аудитории (переключатель на старте)

- **8–9 класс** — выбор профиля: план через кружки, олимпиады, профильные классы
- **10–11 класс** — выбор пути после школы: прицельные пробы, дни открытых дверей
- **Студент/взрослый** — смена направления и выгорание: малые платные пробы без увольнения

## Архитектура защиты от «сломанной судьбы»

1. **Гипотезы, не вердикты** — результат формулируется как «направления для исследования»
2. **Обязательные пробы** — план проверки руками выдаётся вместе с результатом
3. **Живой консультант** — платная глубокая диагностика только со специалистом
4. **Пересмотр** — карта актуальна 1–2 года, продукт просит перепройти
5. **Расхождение — ценность** — противоречие с ощущениями = материал для разговора
6. **Честные границы** — RIASEC не измеряет способности, характер, «пригодность»; об этом — на старте и в отчёте
