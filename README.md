# feco-prof — Профпроба: карта склонностей + Икигай-лист

Бесплатный вход в вертикаль профориентации, два слоя:

1. **Профпроба** (RIASEC, 30 вопросов, 12 минут) — карта склонностей: результат — гипотезы направлений (не «профессия-вердикт») + план проверки руками.
2. **Икигай-лист** — саморефлексия по 4 кругам (люблю / умею / миру нужно / платят): достраивает то, что тест измерить не может. Пользователь пишет сам, затем синтез: кандидаты с 4 подтверждёнными кругами = «кандидаты икигая», с 3 — «рядом» (показывается недостающий круг как конкретное задание). Финал — «формула икигая» со статусом **рабочая гипотеза на 3–6 месяцев**.

Честность: диаграмма 4 кругов — западная адаптация (Уинн, 2001) японского понятия ikigai; в продукте это указано прямо.

## Три аудитории (переключатель на старте)

- **8–9 класс** — выбор профиля: план через кружки, олимпиады, профильные классы
- **10–11 класс** — выбор пути после школы: прицельные пробы, дни открытых дверей
- **Студент/взрослый** — смена направления и выгорание: малые платные пробы без увольнения

## Как продукт защищает от «сломанной судьбы» (архитектура, не дисклеймер)

1. **Гипотезы, не вердикты** — результат формулируется как «направления для исследования»
2. **Обязательные пробы** — вместе с результатом выдаётся план проверки руками (2–3 реальные пробы до решения)
3. **Живой консультант** — платная диагностика только со специалистом; самотестирование при выгорании искажено, и об этом сказано прямо
4. **Пересмотр** — карта актуальна 1–2 года, продукт открыто просит перепройти
5. **Расхождение — ценность** — если результат противоречит ощущениям, это материал для разговора, а не ошибка
6. **Честные границы** — явно указано, что инструмент НЕ измеряет: способности, характер, «пригодность»

## Экономика вертикали (см. также программа обучения, урок p8)

| Продукт | Цена | Роль |
|---|---|---|
| Профпроба (этот файл) | бесплатно | воронка, вирусный формат |
| Диагностика+ (подросток) | 6–14 тыс. ₽ | трек + час с консультантом + план на год |
| Перезагрузка карьеры (взрослый) | 14–25 тыс. ₽ | выгорание, смена направления |
| B2B школы/компании | 30–60 тыс. ₽ | расстановка и мотивация команды |

**Партнёр:** платные пакеты ведёт живой психолог-профконсультант (лицензированные методики). Наша роль — конвейер: интерактивная диагностика, кабинет, отчёты, продажи.
